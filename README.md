# Виджет банковских опреаций

## Описание:

Проект представляет собой бэкенд-часть новой фичи личного кабинета клиента крупного банка. Данный модуль готовит и обрабатывает данные о последних успешных банковских операциях пользователя для их корректного отображения в интерфейсе виджета.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:AnnaP43/PythonProject.git
```
2. Установите зависимости:
```
pip install poetry 
```
## Использование:

### 1. Модуль маскирования и работы с датами (`src/widget.py`)
* **`mask_account_card(data_str)`** — автоматически распознает тип источника (карта или счет) и маскирует его номер. Для карт отображаются первые 6 и последние 4 цифры, для счетов — только последние 4 цифры, предваренные звездочками.
* **`get_date(date_str)`** — принимает строку с датой в формате ISO (например, `"2024-03-11T02:26:18.671407"`) и преобразует её в привычный формат `"11.03.2024"`.

### 2. Модуль фильтрации и сортировки (`src/processing.py`)
* **`filter_by_state(data, state)`** — фильтрует список транзакций по их статусу (по умолчанию оставляет только `"EXECUTED"`).
* **`sort_by_date(data, reverse)`** — сортирует массив операций по дате от самых свежих к старым.
